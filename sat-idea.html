SAT Question Tagging & Practice PDF Tool

Client Proposal

Project Overview

The SAT Question Tagging & Practice PDF Tool is a web application designed to help SAT tutors quickly create custom practice materials tailored to their students’ needs. The tool allows organizing questions by topic, skill, or difficulty, and easily generating practice PDFs for focused student practice.

Key Features (MVP)

1. Question Management

  • Store SAT questions from officially released sources:
    • College Board SAT Practice Tests (1–10)
    • Digital SAT Practice Tests
    • Khan Academy SAT questions
    • Publicly released QAS tests
  • Add, edit, or remove questions manually
  • Include section metadata (Reading, Writing, Math) and source information

2. Tagging System

  • Add multiple custom tags to each question (e.g., “quadratic,” “semicolon,” “comma splice”)
  • Tags help identify specific skills or problem types
  • Search and filter by tags, section, or source

3. Search & Filter

  • Find questions by keywords, tags, section, or source
  • Helps create targeted practice for students needing help in specific topics

4. Packet Builder & PDF Export

  • Select questions to build a custom practice packet
  • Reorder questions as needed
  • Export as a clean, professional PDF
  • Option to include answers for tutor reference

5. User Authentication

  • Secure login for tutors
  • Ensures private access to questions and packets

Benefits for Tutors

  • Save time creating targeted practice materials
  • Quickly find questions on specific topics
  • Generate professional PDFs for students in minutes
  • Keep all questions organized in a single private platform
